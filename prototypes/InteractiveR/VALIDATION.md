# Prototype validation, 31 October 2026

Windows standalone prototype, based on `a7836b49`, using installed 64-bit R 4.6.1 and WebView2. No changes to the released application, version, engine, release tags or installer projects.

- **43 native helper checks passed in each of 30 fresh processes.** Genuine interactive console input, Unicode, source/input separation, stale input replies, Stop during `readline`, menus, incomplete input, sleep and loops, retained variables, error recovery, native/child output isolation, input byte limits and shutdown while awaiting an answer. Also verifies all six standard packages, `t.test`, `power.t.test`, BLAS/LAPACK matrix operations, Cairo SVG output and Windows source/continuation line endings. All 30 processes exited successfully.
- **30 adapter integration checks passed.** Includes `on.exit` cleanup during interruption, validation before state changes, Restart during a prompt without answering it, public request IDs remaining unique across Restart, two independent sessions, source and Console sharing variables, no repeated chart after non-graphical commands, SVG follow-on edits, immutable earlier image assets and two plots in one command. The unchanged on-disk `TPaired.R` example and current paired-t recipe each produce one complete agreement chart, with their canonical SVG matching an independent ordinary R render including the final caption. Separate intended pages and loop plots are retained; two panels within one page produce one image.
- **8 shared UI model checks passed.** Exact shared Web assets from Mac prototype `09dcfcdc80604e7259d478983f9ea7ceb0e36f8a`; only the Node test import path differs for the Windows directory layout.
- **21 actual WebView2 UI checks passed.** Real Run/Stop/Restart controls and input fields exercise the native R session. Includes prompt answers excluded from executable history, rejected-answer retry, invalid-source recovery, multiline input, history recall/draft restoration, Script retention after Restart, escaped output, visible SVG revisions and resolution of the original earlier plot asset. The actual unchanged paired-t example, submitted once through Script Run, produces one completed plot event and one displayed image after its numerical output. Original Open/Copy button nodes survive focus/selection changes and updates received while the pointer is held down, and still dispatch their original chart revision on release.

Two initial apparent plot failures were test assertions that did not allow spaces in SVG `rgb(100%, 0%, 0%)` color notation. The SVGs contained the expected red line; assertions were corrected and the complete suite rerun.

Real issues found and fixed during validation: native GraphApp export lookup, stale request-ID collision after Restart, rejected input leaving the console busy, late-generation lifecycle updates, repeated unchanged plot previews, WebView2 event delivery, numeric/string request-ID mismatch, loss of wrapped-command history navigation and revision-ambiguous chart actions. The shared interface fixes were coordinated with the Mac prototype.

The full paired-t example exposed further prototype gaps: R's standard statistics DLL dependencies needed the installed R binary directory on the helper's own PATH; native console input needed CRLF/CR normalization; and base graphics panel hooks needed `par('page')` to distinguish new pages from panels. These are fixed without changing any recipe or the parent process environment. One pre-fix startup exited with a heap-corruption status; it did not recur in 30 fresh processes after these changes, but the causal link has not been established.

A later chart-button regression deterministically failed on the original shared UI: a collapsed selection/focus change replaced the original button nodes before a pointer click could finish. Shared fix `09dcfcdc` redraws the transcript only for changed content and defers replacement until after pointer release/click. Real Windows pointer press/release checks additionally confirmed that Copy completes with the SVG/PNG/bitmap notice, and Open displays the original SVG in the associated viewer; closing that viewer leaves the R console ready. This is a timing-dependent defect, so a successful quick click alone does not replace the retained-node regression.

Stop is cooperative: this evidence does not claim interruption of arbitrary native code that never checks R interrupts. Restart explicitly replaces the process and loses its workspace. Completed assignments and file writes are retained after Stop. Native interactive graphics such as `locator()` and arbitrary terminal programs are outside this prototype's supported interface.

The native and integration test programs retain their actual JSON/event evidence in their designated output folders. `--ui-smoke` writes a JSON result and PNG screenshot. A separate prototype executable is produced; no installer is built or overwritten.
