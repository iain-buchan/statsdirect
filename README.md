This is the source code for www.statsdirect.com statistical software.

It is a 100% C# project targeting .Net and has two Microsoft Windows specific components: Spreadsheet Gear (www.spreadsheetgear.com) for data management, and Devexpress RichEdit (www.devexpress.com) for report editing. The classes that wrap these components are designed to swap alternatives in/out.

The code is evolving toward a cross-platform application with generative AI interaction. The history of the code is described at www.statsdirect.com/technology.aspx.

The work is supported as free and open resource by The University of Liverpool, Leap of Faith Ventures and StatsDirect Ltd.
