    Worksheet Learn and AI Assist

    The Windows worksheet toolbar has two ways to get guidance. Learn opens the lesson library, including worked examples and practice questions that you can use without an AI connection. AI Assist opens a conversation for the current workbook.

    Ask a question

    Ask how to organise or analyse your data. The assistant uses excerpts from the Help bundled with StatsDirect. Start with Question only to ask without sharing the workbook. When you press Send, ChatGPT receives your question and can use the relevant Help. Leave names, patient identifiers and other confidential information out of your question. In ordinary use, the recent conversation also provides context. Choose New conversation to leave earlier shared content out.

    If you want advice based on worksheet values, open Sharing, select Share data from the workbook named in the pane, and confirm that you have removed person identifiers. This covers that workbook for the current application session. Another open workbook needs its own confirmation. Simply visiting it does not remove the first workbook's confirmation. Turn sharing off to stop further workbook reads.

    Review proposed worksheet edits

    1. With sharing confirmed, you can ask for an edit, such as adding an age band to a new column. One proposal can write literal numbers, text, TRUE or FALSE, or blanks to up to 4,000 cells in one rectangular range.
    2. In the original worksheet, choose Review worksheet edit. Check the range and the Before and After values. A replacement value can overwrite an existing formula. If the worksheet has changed since the proposal, ask for a new edit.
    3. Choose Apply edits to write the previewed changes, or Cancel to keep the sheet as it was. One Undo reverses the entire applied edit.

    Run a suggested analysis

    In the original worksheet, select the cells you intend to analyse and choose Review analysis. The preview shows the method, source worksheet, selected cells, expected input and report destination. You can cancel and check the selection before reopening the review. If the workbook was shared for the suggestion, ask again after changing its data or selection.

    Run and add to report opens StatsDirect's usual analysis setup so you can check the input and choose any required settings. StatsDirect runs the calculation locally and puts the result in the report named in the review, or creates a report if none is open. Running it does not send its data or results to ChatGPT.

    The assistant can propose seven methods:

    • Paired Student t test
    • Unpaired Student t test
    • Wilcoxon signed ranks test
    • Spearman rank correlation
    • General analysis of agreement
    • Univariate descriptive summaries
    • Tests for departure from normality

    For another method, use Analyse on the worksheet toolbar.

    Using AI Assist under an organisation's policy

    When your organisation restricts data sharing (level 2), AI Assist can still answer questions using packaged Help and suggest an analysis for you to review and run locally. Workbook sharing and worksheet edit proposals are unavailable. Each request sends the question you type and relevant Help, while your workbook, earlier conversation and local results stay on your computer.

    When your organisation restricts AI (level 3), AI Assist cannot connect. Learn, local help, and the analyses on the Analysis menu remain available. See Script AI for sign-in and Windows policy details.
